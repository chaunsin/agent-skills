# git stack

解决代码提交，推送，合并冲突操作。

> **注意** : 在开始之前需读取项目中得AGENTS.md,CLAUDE.md,README.md中得提交规范。如存在则规则优先级为: 用户提示词 > AGENTS.md > 本技能

## 使用场景

1. 用户说：提交代码，推送代码，push代码。
2. 解决代码合并冲突问题。
3. 创建工作树worktree
4. 合并提交信息，变基，rebase。
5. 发版打tag标签

## 门禁

1. 相关git操作必须在有`.git/` 管理的目录下操作，否则退出并引导用户创建工作区或切换到对应工作区目录。
2. 宿主机需要提前安装好git CLI，否则退出并引导用户安装git CLI 以及授权等.

## 功能列表

| 功能 | 链接 | 说明 |
| ----------- | ---------- | -------------- |
| 代码提交 | ./commit | 代码提交 |
| 代码合并冲突 | ./conflict | 代码冲突解决。 |
| 工作区worktree | ./worktree | 工作区，worktree创建 |
| PR、Issues、github相关操作 | | 优先使用`gh`操作相关技能,没有则直接使用`gh`命令 |

## 危险操作

- 永远不要更新 Git 配置
- 未经明确请求，切勿运行破坏性命令（例如 --force、硬重置）。
- 除非用户要求，否则绝不跳过钩子（--no-verify）。
- 切勿强行推送至主目录/主分支
- 如果由于钩子导致提交失败，请修复并创建新的提交（不要修改现有提交）。
