# SPEC 文档模板

默认根据 PRD 文档内容填写；用户明确提供或指定 ADR、访谈、QA 等材料时，
直接使用对应来源，不要求补齐 PRD 格式。生成文档默认使用中文，用户指定其他语言时遵循其要求。

保留主要章节层次，按改动规模调整子章节的详细程度。不涉及的部分简述“不适用”及原因，
不要为填写模板虚构接口、数据表、性能指标或任务。下列占位内容应替换为实际设计。

来源引用优先沿用已有的需求、决策或问题编号；没有编号时使用章节、访谈位置，
或明确标注的本地引用编号。不能伪造用户故事、确认状态或外部 Issue。
