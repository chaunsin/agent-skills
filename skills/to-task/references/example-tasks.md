# 记录导出任务计划示例

> 本示例为虚构场景，仅说明数据格式。计划仍含人工决策，属于草案；未执行任何任务。

## 示例输入

1. 登录用户可以点击下载 CSV，仅包含自己的记录；下载失败应有可读提示，不产生误导性的成功反馈。
2. CSV 字段列表及顺序由产品负责人决定，确定前先生成拆解草案，不自行选字段。
3. 复用现有登录和浏览器下载流程，不新建登录方案；不包含定时导出和通知。

## 计划信息

- 格式版本：`1.0`
- 计划 ID：`record-csv-export`
- 修订号：`1`
- 项目：示例记录管理应用
- 目标：让登录用户下载仅包含本人记录的 CSV，并在下载失败时获得明确反馈。

本报告对应 [example-tasks.json](example-tasks.json)，由同一份数据生成。

| REQ-002 | CSV 字段列表及顺序由产品负责人决定，确定前先生成条件式拆解草案。 | example-tasks.md 的示例输入第 2 条 | EXP-001、EXP-002 |

## EXP-001：确认 CSV 字段及顺序

- 类型：`human`；优先级：`P1`；状态：`pending`。
- 目标：获得可供实现和验证使用的人工确认字段清单。
- 对应需求：REQ-002
- 前置依赖：无

**范围**

- 确认 CSV 列名及列顺序，并记录人工确认来源。

**范围外**

- 实现导出功能。
- 由 Agent 自行替产品负责人选择字段。

**输入**

- 示例请求中关于字段决策的要求。

**输出**

- 包含列名、顺序及人工确认来源的决策记录。

**约束**

- 拆解阶段只定义决策任务，不主动联系产品负责人。

**验收与验证**

| 验收 ID | 完成条件 | 验证方法 |
| --- | --- | --- |
| AC-1 | 决策记录列明全部导出列及顺序，并能够追溯人工确认来源。 | 审阅决策记录，核对列名、顺序和人工确认来源均已明确。 |

## EXP-002：交付手动导出本人记录的完整切片

- 类型：`implementation`；优先级：`P1`；状态：`pending`。
- 目标：让现有页面通过受权限约束的导出接口下载本人记录，并处理失败反馈。
- 对应需求：REQ-001、REQ-002、REQ-003
- 前置依赖：EXP-001

**范围**

- 按已确认字段实现导出接口与页面下载交互。
- 使用现有登录身份限制数据范围，并呈现下载失败提示。

**范围外**

- 定时导出、通知和新的登录方案。

**输入**

- EXP-001 产出的字段决策记录。
- 项目现有登录、记录查询和浏览器下载约定。

**输出**

- 导出接口与页面交互变更。
- 覆盖数据隔离、字段顺序和失败反馈的针对性检查。

**约束**

- 字段未确认前不自行决定列名或顺序。
- 复用现有身份验证机制，不扩展数据访问范围。

**验收与验证**

| 验收 ID | 完成条件 | 验证方法 |
| --- | --- | --- |
| AC-1 | 登录用户导出的记录全部属于本人，列名及顺序与人工确认记录一致。 | 使用账号 A、B 的隔离测试数据导出，核对归属、列名及顺序。 |
| AC-2 | 未登录请求不能取得导出数据，也不能通过请求参数读取其他用户记录。 | 在隔离测试环境检查未登录请求及跨账号参数请求，确认没有返回受限记录。 |
| AC-3 | 下载失败显示可读提示，页面不显示下载成功。 | 模拟导出失败，检查页面错误反馈和成功反馈互斥。 |

## EXP-003：验证浏览器与接口组合后的导出行为

- 类型：`integration`；优先级：`P1`；状态：`pending`。
- 目标：验证完整下载链路保留数据隔离约束和失败反馈。
- 对应需求：REQ-001、REQ-003
- 前置依赖：EXP-002

**范围**

- 在隔离环境验证登录、触发导出、读取下载文件的完整流程。
- 验证接口失败在真实页面中的呈现。

**范围外**

- 生产发布或使用真实用户数据。

**输入**

- EXP-002 的接口与页面产物。
- 可运行应用的隔离环境，以及两个测试账号和固定测试记录。

**输出**

- 由执行者填写的集成检查结果及问题记录。

**约束**

- 执行环境和测试账号就绪后才能进行检查；规划阶段不填写通过结果。

**验收与验证**

| 验收 ID | 完成条件 | 验证方法 |
| --- | --- | --- |
| AC-1 | 浏览器实际下载的 CSV 与当前测试账号的固定记录一致，不包含另一账号数据。 | 通过浏览器完整操作并读取下载文件，与测试数据逐项核对。 |
| AC-2 | 接口失败时页面显示可读错误，不提示下载成功。 | 在隔离环境使导出接口返回失败，观察完整交互并记录结果。 |
