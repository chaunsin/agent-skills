# 示例参考资料

本文件是用于演示引用方式的虚构资料，将 PRD、SPEC 和交互设计片段放在同一文件中。
实际拆解应引用用户提供或项目中真实存在的文档，不生成虚构文档来代替缺失来源。

## PRD

1. 登录用户可以手动下载自己的 CSV 记录，不能导出其他用户的数据。
2. CSV 字段列表及顺序由产品负责人决定；确认前只形成条件式任务草案。
3. 下载失败应显示可读错误，不产生误导性的成功反馈；复用现有登录和下载流程。
4. 本次排除定时导出、通知和新的登录方案。

## SPEC

- 导出接口复用现有登录身份与记录查询能力，返回数据须限制为当前用户的记录。
- CSV 的列名和顺序以已确认的字段清单为准，不能在拆解阶段自行选择。
- 验证需覆盖未登录、跨账号参数和接口失败场景；使用隔离环境及固定测试数据。

## 设计

- 用户在现有页面触发手动下载，沿用已有浏览器下载交互。
- 下载失败时展示可读错误，不能同时出现下载成功提示。
- 本示例没有独立设计稿 URL；真实任务有设计稿时，应保留用户提供的链接及相关节点。
