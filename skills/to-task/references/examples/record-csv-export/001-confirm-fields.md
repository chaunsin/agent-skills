# EXP-001：确认 CSV 字段及顺序

计划与需求来源：[记录导出任务索引](index.md)。
本任务为规划草案，尚未执行；相关数据见 [tasks.json](tasks.json)。

- 类型：`human`；优先级：`P1`；状态：`pending`。
- 目标：获得可供实现和验证使用的人工确认字段清单。
- 对应需求：REQ-002
- 前置依赖：无

## 范围

- 确认 CSV 列名及列顺序，并记录人工确认来源。

## 范围外

- 实现导出功能。
- 由 Agent 自行替产品负责人选择字段。

## 输入

- 记录导出 PRD 中关于字段决策的要求。

## 输出

- 包含列名、顺序及人工确认来源的决策记录。

## 参考资料

| 资料 | 定位与版本 | 与本任务相关的内容 |
| --- | --- | --- |
| [记录导出 PRD](../source-docs.md#prd) | PRD，第 2 条 | CSV 字段列表及顺序由产品负责人确认；本任务提供决策记录，不自行选择字段。 |

## 约束

- 拆解阶段只定义决策任务，不主动联系产品负责人。

## 验收与验证

| 验收 ID | 完成条件 | 验证方法 |
| --- | --- | --- |
| AC-1 | 决策记录列明全部导出列及顺序，并能够追溯人工确认来源。 | 审阅决策记录，核对列名、顺序和人工确认来源均已明确。 |

## 未决问题与假设

Q-001：产品负责人确认的 CSV 字段列表及顺序是什么？本任务负责提供人工决策，直接影响 [EXP-002](002-export-records.md)。

无额外假设。
