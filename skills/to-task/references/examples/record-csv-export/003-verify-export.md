# EXP-003：验证浏览器与接口组合后的导出行为

计划与需求来源：[记录导出任务索引](index.md)。
本任务为规划草案，尚未执行；相关数据见 [tasks.json](tasks.json)。

- 类型：`integration`；优先级：`P1`；状态：`pending`。
- 目标：验证完整下载链路保留数据隔离约束和失败反馈。
- 对应需求：REQ-001、REQ-003
- 前置依赖：[EXP-002](002-export-records.md)

## 范围

- 在隔离环境验证登录、触发导出、读取下载文件的完整流程。
- 验证接口失败在真实页面中的呈现。

## 范围外

- 生产发布或使用真实用户数据。

## 输入

- EXP-002 的接口与页面产物。
- 可运行应用的隔离环境，以及两个测试账号和固定测试记录。

## 输出

- 由执行者填写的集成检查结果及问题记录。

- 执行环境和测试账号就绪后才能进行检查；规划阶段不填写通过结果。

## 验收与验证

| 验收 ID | 完成条件 | 验证方法 |
| --- | --- | --- |
| AC-1 | 浏览器实际下载的 CSV 与当前测试账号的固定记录一致，不包含另一账号数据。 | 通过浏览器完整操作并读取下载文件，与测试数据逐项核对。 |
| AC-2 | 接口失败时页面显示可读错误，不提示下载成功。 | 在隔离环境使导出接口返回失败，观察完整交互并记录结果。 |
